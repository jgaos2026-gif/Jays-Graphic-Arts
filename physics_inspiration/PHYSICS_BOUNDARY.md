# Physics Boundary

**Author:** John E. Arenz — JGA Enterprises, Mendota, Illinois

> This document defines the exact boundary between what this repository claims about physics and what it does not claim.

---

## What BCT Claims About Physics

**Nothing.** BCT makes no claims about physical reality.

---

## What BCT Borrows From Physics (Labeled [INSPIRATION])

The following physical concepts are structural inspirations. They are not evidence for BCT, and BCT does not depend on them being physically correct.

| Physics concept | What BCT borrows |
|---|---|
| Worldlines | The idea that identity travels with a strand through time |
| Topological QC | That braid crossings can carry computational meaning |
| String theory | That persistent one-dimensional objects with structured interactions can form higher-order organization |
| Simulation theory | The design intuition that efficient history representation uses causal structure |

---

## What BCT Explicitly Does Not Claim

- That the universe is a braid
- That BCT implements quantum computation
- That string theory validates BCT
- That simulation theory is true
- That physical laws support BCT's architectural choices

---

## Why This File Exists

Reviewers will look for places where physics is used as evidence rather than inspiration. This file makes the boundary explicit so the distinction cannot be missed.

Every document in `physics_inspiration/` carries appropriate labels. If you find a claim in this repository that treats physical inspiration as physical evidence, that is an error — please open an issue.
