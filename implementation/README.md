# Implementation

This directory contains implementation artifacts for the BCT research program.

| Directory | Contents |
|---|---|
| `prototype/` | Early-stage prototype implementation of BCT execution model |
| `simulator/` | BCT instruction set simulator (primary development target) |
| `examples/` | Example executable braids demonstrating each instruction family |
| `benchmarks/` | Benchmark implementations for H1–H6 |

## Status

**Current maturity:** Early prototype. The simulator is the primary development priority (Phase 2).
