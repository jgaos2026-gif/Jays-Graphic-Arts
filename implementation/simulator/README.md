# Simulator

The BCT instruction set simulator is the primary Phase 2 deliverable.

**Status:** Planned — design pending formal semantics (OP-2).

**Design goals:**
- Correct implementation of all six instruction families
- Full evidence log with append-only semantics
- Three-tier memory model
- Benchmark harness integration
- Reproducible execution from evidence log

**Target platforms:** x86-64, ARM64

**Language:** TBD (candidates: Rust, Go, C++)
