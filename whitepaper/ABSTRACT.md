# Abstract

**Author:** John E. Arenz — JGA Enterprises, Mendota, Illinois

---

Modern computers are largely built around trees, graphs, queues, stacks, and linear memory models. This research investigates an additional architectural family: **Braided Computational Topology (BCT)**.

BCT proposes that executable braid topologies can serve as computational structures for verification, authority, routing, recovery, memory, provenance, distributed execution, and AI reasoning. Rather than representing computation solely as state transitions, BCT explores whether executable braid topologies can preserve execution history, authority, verification evidence, and recovery pathways without discarding structural information.

Six executable braid instruction families are defined and implemented in a working simulator: Integrity, Routing, Recovery, Role Exchange, Authority, and Memory. A layered eight-stage computational architecture is specified. A braid instruction set architecture (ISA Alpha 0.1) with 28 opcodes is defined. Open research questions and six falsifiable hypotheses are stated.

This work is a research prototype. Current results are architectural specifications, a working simulator with 7 passing tests, and formal definitions. Empirical benchmarks (Hypotheses H1–H5) have not yet been run. Independent validation has not yet been obtained. The research explicitly invites critical review, independent reproduction, and attempted falsification.
