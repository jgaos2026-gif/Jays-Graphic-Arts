# Code of Conduct

## Our Pledge

This is a research repository. Contributors and participants pledge to engage with the work honestly, rigorously, and respectfully.

We are committed to:

- Honest representation of claims (established vs. original vs. hypothetical)
- Rigorous mathematical and empirical standards
- Respectful treatment of contributors, reviewers, and critics
- Welcoming independent scrutiny and falsification attempts
- Crediting prior work accurately

## Standards

**Positive behaviors:**

- Clearly distinguishing established mathematics from original contributions
- Identifying hypotheses as hypotheses, not facts
- Providing evidence when making claims
- Welcoming criticism, corrections, and independent verification
- Engaging constructively with reviewers who disagree
- Citing prior work accurately and completely

**Unacceptable behaviors:**

- Claiming established mathematics as original contributions
- Presenting hypotheses as proven results
- Dismissing rigorous criticism without engagement
- Misrepresenting the maturity or production-readiness of this research
- Plagiarism or attribution violations

## Research Integrity

BCT is a research program in early stages. Claims in this repository are:

- Formal definitions (marked as such)
- Research hypotheses (marked as such)
- Prototype implementations (not production systems)
- Open questions (marked as such)

No part of this repository should be represented as validated production technology unless explicitly marked with independent validation results.

## Reporting

If you observe violations of this code of conduct or identify errors in the research, open an issue in this repository with a clear description and evidence.

## Scope

This Code of Conduct applies within all repository spaces, including issues, pull requests, and discussions.

## Attribution

This Code of Conduct is adapted from the Contributor Covenant, version 2.1, and extended with research integrity standards specific to this project.
